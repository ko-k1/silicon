# A14 / iOS 27.0.1 (24A446) research baseline

- Date: 2026-11-05
- Target manifest: `targets/manifests/iphone12mini-ios27.0.1.yaml`
- Cases: `CASE-0001`, `CASE-0002`, `CASE-0003`
- Status: documentary and build-artifact baseline; no device runtime measurement

## Scope

This report establishes what can be supported about an A14 / iPhone 12 mini running iOS 27.0.1 build 24A446 from public documentation, Apple release metadata, and offline build-artifact inspection. It deliberately excludes exploit chains, kernel read/write primitives, bypass techniques, patch offsets, persistence, and protection-disablement procedures.

## Protection mechanism

Apple's 2026-01-28 Operating system integrity page places A12-A14 in the PPL column and documents SPTM for A15-or-later and M2-or-later SoCs (`EVD-0002`, `EVD-0003`). The guide's revision history does not list that page as updated after January 2026 (`EVD-0013`).

The 24A446 build artifacts for iPhone13,1 show an SPTM/TXM configuration:

- BuildManifest entries include `Ap,SecurePageTableMonitor` -> `Firmware/sptm.t8101.release.im4p` and `Ap,TrustedExecutionMonitor` -> `Firmware/txm.iphoneos.release.im4p`.
- `VariantContents` marks `InstalledSPTM` and `RestoreSPTM` as `Production`.
- The decompressed kernelcache has top-level Mach-O segments `__DATA_SPTM` and `__TEXT_BOOT_EXEC`; `__PPLTEXT`, `__PPLDATA`, and `__PPLDATA_CONST` are absent from the segment list and from a byte scan of the full image.

The 24A446 BuildManifest for iPhone13,4, a second A14 product type, independently contains the same SPTM/TXM entries and `Production` markers (`EVD-0014`, `VAL-0004`). The build-level finding is therefore not specific to iPhone13,1.

Evidence: `EVD-0010` (`VAL-0002`), `EVD-0012` (`VAL-0003`), and `EVD-0014` (`VAL-0004`). Secondary September 2026 reports are consistent with this change (`EVD-0006`-`EVD-0008`); a contemporaneous survey and a 2026-11-04 community tracker repeat the older PPL model and are retained as counter-evidence (`EVD-0009`, `EVD-0015`).

**Assessment:** at the build level, the checked A14 24A446 images use **SPTM/TXM**, not PPL. Confidence is high for the build contents. The runtime state of SPTM/TXM on the exact device remains `unknown`.

## Vulnerability baseline

Apple's iOS 27 / iPadOS 27 advisory (`APPLE-SA-149034`, `SRC-0003`) contains 163 CVE entries. Of those:

- 161 are in the iPhone 11-and-later range that includes A14 devices.
- 25 are in the `Kernel` component.
- 30 have a kernel-related impact or category.
- 10 are sandbox-related; 7 have a privilege-escalation-related category.
- 0 explicitly name PPL, SPTM, TXM, page tables, code signing, or trust cache.

Apple's security-releases index states that iOS 27.0.1 / iPadOS 27.0.1 (24A446) has no published CVE entries (`EVD-0004`). The register is in `research/public-research/ios27-vulnerability-register.yaml` and `.md`; see `CASE-0002`.

These are register facts, not severity ratings or exploitability findings. The advisory does not map any CVE to a PPL/SPTM/TXM bypass.

## Public bypass research scope

The reviewed Dopamine 3.0 release lists stable A14/M1 support at iOS 16.6 through 17.3.1; Titan's own claimed range extends to 17.4 beta 3 (`EVD-0009`, `EVD-0011`). Momentarius is reported as an A12/A13 PPL bypass for iOS 16.6-18.7.1 and 26.0-26.0.1 (`EVD-0011`). The Apple Wiki lists momentarius for iOS 27 but does not state A14 support in the reviewed text (`EVD-0006`).

A 2026-11-04 community tracker still frames A14/M1 as PPL and says A14+ needs an n-day SPTM bypass, but it provides no build-specific measurement (`EVD-0015`). It is retained as counter-evidence.

No reviewed source demonstrates an A14-specific PPL or SPTM bypass on 24A446. This is an evidence gap, not proof that none exists. Because the checked 24A446 A14 images are SPTM/TXM-based, an "A14 PPL bypass" is mis-scoped for this build. See `CASE-0003`.

## What is established

- The 24A446 restore images for iPhone13,1 and iPhone13,4 package SPTM and TXM and mark installed SPTM as a production component.
- The iPhone13,1 kernelcache is structurally an SPTM build, with no PPL segment names.
- Apple's 27.0 advisory provides a 163-CVE register; 27.0.1 has no published CVE entries.
- The reviewed public bypass record does not demonstrate A14 coverage on 24A446.

## What remains unknown

- Whether the physical target device is an iPhone13,1 running 24A446.
- Whether SPTM/TXM is active, correctly configured, and enforcing on the exact device.
- Whether any boot path uses a fallback configuration.
- Whether any CVE in the 27.0 advisory is a protection-bypass primitive.
- Whether any unreleased or private A14/24A446 bypass exists.

## Limitations

- No device was available for metadata or runtime observation.
- Build packaging and kernelcache structure are not runtime measurements.
- The second A14 product type check covers packaging only; the iPhone13,4 kernelcache was not inspected.
- The public bypass record is incomplete and community-maintained; a tracker still frames A14/M1 as PPL without a build-specific measurement.
- The Apple advisory covers iOS 27, not build 24A446 specifically.
- The target manifest's device identity fields remain `pending`.

## Next steps

1. Verify product type, SoC, OS version, and build on the owned device using non-invasive metadata (`VAL-0001`).
2. Keep runtime protection states `unknown` until observed; do not upgrade build-level inferences to runtime facts.
3. Re-check public sources for A14/24A446-specific claims and record their exact scope and date.
4. Keep exploit reproduction, bypass tooling, and device modification out of scope.
